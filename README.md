## Cómo trabajo

Busco que cada sistema tenga una estructura entendible, controles de integridad y una experiencia simple para la persona que realmente lo utiliza. Según el proyecto, trabajo con:

- separación entre datos, lógica y presentación;
- validaciones y mensajes de error comprensibles;
- bitácoras y trazabilidad;
- pruebas automatizadas y verificaciones de regresión;
- respaldos y recuperación;
- documentación de instalación, operación y mantenimiento;
- interfaces sobrias orientadas a tareas concretas.

El catálogo histórico y la convención local de proyectos se mantienen en [PROJECT_CATALOG.md](PROJECT_CATALOG.md).
